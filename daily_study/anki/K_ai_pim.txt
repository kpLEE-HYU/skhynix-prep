Memory wall이란?	연산 성능은 빠르게 느는데 메모리 대역폭·데이터 이동이 못 따라가 시스템이 메모리에서 막히는 현상. AI의 진짜 병목은 연산이 아니라 데이터 이동(에너지·지연).	aipim P3 지원서연계
Memory wall의 두 가지 해법은?	① 메모리를 연산기 가까이 붙여 대역폭↑(HBM, 외부 해법) ② 연산을 메모리 안에 넣어 데이터 이동 제거(PIM, 내부 해법).	aipim P3 지원서연계
PIM(Processing-in-Memory)이란?	연산 유닛을 메모리 안/근처에 둬 데이터를 칩 밖으로 안 옮기고 처리. 외부 핀보다 훨씬 큰 내부 DRAM 대역폭을 활용해 memory wall 완화.	aipim P3 지원서연계
PIM이 memory wall을 해결하는 핵심 원리는?	DRAM 내부 대역폭이 외부 핀 대역폭보다 훨씬 큼. 연산을 bank 안에 둬 데이터를 밖으로 안 옮기고 내부 대역폭으로 바로 계산 → 속도↑, 데이터 이동 전력↓.	aipim P3 지원서연계
