HBM을 쓰는 이유는?	AI/HPC의 병목은 메모리 대역폭(memory wall). HBM은 초광대역 I/O를 moderate 클럭으로 굴려 bit당 에너지 최저 + 대역폭 최고 + 패키지 내 집적을 동시에 달성.	hbm P2
TSV란?	Through-Silicon Via. DRAM die를 수직 관통하는 구리 via로, 적층된 die들을 위아래로 잇는 전기 통로. die 사이는 micro-bump로 접합.	hbm P2
HBM base(logic) die의 역할은?	스택 최하단 die로 외부 인터페이스·테스트·전력 분배 담당. 2.5D 인터포저로 GPU와 연결. HBM4부터 커스텀 로직을 넣어 로직 파운드리 공정으로 제작.	hbm P2
HBM 대역폭 공식은?	대역폭 = I/O 폭 × per-pin 데이터 속도 ÷ 8(byte 환산).	hbm P2
HBM3 대역폭 계산은?	1024-bit × 6.4Gbps ÷ 8 = 819 GB/s (per stack).	hbm P2
HBM3E 대역폭 계산은?	1024-bit × 9.6Gbps ÷ 8 ≈ 1.23 TB/s (per stack).	hbm P2
HBM4 대역폭 계산은?	2048-bit × 8Gbps(JEDEC) ÷ 8 = 2.0 TB/s. SK하이닉스 10Gbps → 약 2.5 TB/s.	hbm P2
HBM3E 핵심 스펙은?	1024-bit IO, 9.2~9.6 Gbps/pin, 12-Hi=36GB(12×3GB), ≈1.2 TB/s/stack. SK하이닉스 세계 첫 12-Hi 36GB 양산, 16-Hi 48GB 샘플.	hbm P2
HBM4의 가장 큰 변화는?	I/O 폭이 1024→2048-bit로 2배(2015년 이후 처음). 독립 채널 16→32(채널당 pseudo-channel 2개). base die를 로직 파운드리 공정으로 제작.	hbm P2
HBM4 JEDEC 확정 시점과 양산 시기는?	JEDEC JESD270-4가 2025년 4월 확정. 2026년 양산(SK하이닉스 개발 완료, 삼성 2026.02 양산 발표). 엔비디아 Vera Rubin용.	hbm P2
HBM4 per-pin 속도와 용량은?	JEDEC 기준 8Gbps(2.0TB/s), SK하이닉스 10Gbps(약 2.5TB/s+, JEDEC 대비 25%↑). 16-Hi=48GB.	hbm P2
HBM 스택 8/12/16-Hi란?	die를 8/12/16층 적층한 것. 같은 높이에 더 쌓으려 die를 40% 박형화. 층수↑ = 용량↑, but warpage·발열·TSV 정렬 난도↑.	hbm P2
SK하이닉스 HBM 시장 위상은?	2025 HBM 점유 약 52%로 1위, HBM4(2026) ~54% 전망. 엔비디아 HBM의 약 90% 공급, HBM4 물량 약 2/3(70%에 근접) 선점.	hbm P2
HBM과 AI 가속기(GPU)의 관계는?	GPU 연산엔진이 데이터를 굶지 않게 HBM이 2.5D 인터포저에서 TB/s급 대역폭 공급. 용량(GB)=모델 크기 한계, 대역폭(TB/s)=토큰 throughput 한계.	hbm P2
HBM4가 속도보다 I/O 폭을 키운 이유는?	per-pin 속도를 더 올리면 SI·전력 한계에 부딪힘. 폭을 2배로 늘리는 게 같은 대역폭을 더 낮은 에너지로 내는 길.	hbm P2
HBM의 단점은?	TSV·인터포저·스택 본딩으로 공정 난도·원가·발열이 높고 수율 확보가 어렵다.	hbm P2
HBM4 base die를 로직 파운드리에서 만드는 이유는?	고속 인터페이스·연산 로직은 로직 공정이 유리. SK하이닉스는 TSMC와 협업해 base die 제작.	hbm P2
2.5D 패키징이란?	GPU die와 HBM 스택을 실리콘 인터포저 위에 나란히 올려 짧고 넓은 배선으로 연결하는 방식. 3D(수직적층)와 구분.	hbm P2
HBM에서 용량과 대역폭은 무엇으로 결정되나?	용량(GB)=die 적층 수×die 용량(12-Hi×3GB=36GB). 대역폭(TB/s)=IO폭×per-pin속도÷8. 두 축을 분리해서 본다.	hbm P2
HBM 대역폭에서 폭 vs 속도 trade-off는?	광폭은 같은 대역폭을 낮은 per-pin 클럭으로 내 SI·전력 유리하나 인터포저 배선·base die 복잡도↑. 협폭 고속은 DFE 등화 필요. SerDes 설계와 동일.	hbm P2
