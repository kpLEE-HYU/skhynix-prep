## 항목 2 — 경력기술서 (2 프로젝트 개조식, v6)

> 포맷: 프로젝트명/기간/**성과 한 줄(문제 크기+개선폭)**/역할("업무: 내용, 수치")/**기술("도구를 활용한 업무" 번호 형식)**
> KPI 매핑: 성과줄=공수 절감(10명·수십만 건·75%)+TAT(50%↓) / 역할1=신뢰성(유출 0건) / 역할2=정확도 개선형(70→95%) / 역할3=운영 완성도(Perforce→Airflow 무인 실행) / 역할4=정착(피드백 루프)
> JD 매핑: P1 역할1 = JD① "Agent 아키텍처 설계 및 백엔드 개발" / P1 역할2 + P2 = JD② "RAG 시스템 개발·도메인 특화 LLM 파인 튜닝" / P1 역할3 = JD③ "Legacy 시스템 연동" / P1 역할4 = 필수 "커뮤니케이션" + 우대(Multi-Agent·현업 운영·프로덕션 배포)는 P1 전반

```text
[반도체 설계 검증 자동 판정 LLM Multi-Agent 시스템 개발·운영]
· 기간: 2025.09~현재(10개월)
· 성과: 과제당 설계 엔지니어 10명이 수작업하던 수십만 건 위반 검토의 75%를 자동화, 리뷰 TAT 50% 단축(6일→3일)
· 역할:
- Multi-Agent 아키텍처 설계·백엔드 개발: 도메인별 전담 Agent 3종+검증 Agent 교차 확인으로 False Alarm 90% 감축, 실리콘 버그 유출 0건
- 지식베이스 구축: 툴 매뉴얼·판정 이력·설계 스펙 기반 근거 제시로 판정 정확도 70%→95%
- 운영 자동화: 설계 데이터 갱신 시 위반 분석~리포트 발행 자동 수행·상시 운영
- 현업 엔지니어와 격주 오판정 리뷰: 확정 판정 500건 반영, 반복 오판정 80% 감소
· 기술:
1. LangGraph·FastAPI를 활용한 Multi-Agent 시스템 개발
2. Milvus·Neo4j·PostgreSQL을 활용한 RAG 지식베이스 구축
3. Perforce·EDA 툴 연동 MCP 서버 개발 및 Airflow 파이프라인 구축

[반도체 설계 특화 sLLM 개발 (SystemVerilog 파인튜닝)]
· 기간: 2025.01~2025.09(9개월)
· 성과: 코드 분석 정답률 60%→80%, 사내 70B급 공용 모델 대비 1/10 크기로 동등 성능 달성
· 역할:
- 도메인 코퍼스 구축: 설계 코드·검증 툴 문서·설계 스펙 수집, 중복 제거·품질 필터링 — 원본 전체 학습 대비 정답률 +6%p
- 2단계 학습: 도메인 적응 사전학습(DAPT) 후 판정·설명 SFT — SFT 단독 대비 +12%p, 문법을 넘어 설계 의도까지 이해
- 합성 데이터 생성: 70B teacher 모델로 학습쌍 생성, 자동 필터·LLM-as-judge로 선별 — 수작업 대비 공수 90% 절감
· 기술:
1. Qwen2.5-Coder 기반 LoRA 파인튜닝(PyTorch·HuggingFace PEFT)
2. vLLM을 활용한 폐쇄망 GPU 서버 모델 서빙
```
