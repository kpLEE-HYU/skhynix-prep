## ④ AI를 활용한 프로젝트/공모전/논문/연구/문제 해결 경험 (1998자 / 2,000)

> 키워드: Graph DB(Neo4j) 스키마 설계 / 2계층 GraphRAG / 다중 홉 질의 / LangChain 기반 Multi-Agent / Vector DB 통제 A/B 실험 / sLLM 파인튜닝 / 판정 재현성·근거 추적 / 지식 축적 루프 / 계측·검사·Defect 원인 분석 / 시계열
> 프레임: **워크플로우가 아니라 데이터** — 그래프 모델링·통합(#2) → 방식 검증(#3) → 축적 결과(#4)가 한 줄기, 현업 운영 실적(#1)이 도입부 임팩트
> 도메인 차이 인정: 계측·검사는 시계열 중심이라 성격이 다르다는 점을 도입에 명시하고, 전이 가능한 것은 "관계로 묶어 근거를 추적 가능하게 만드는 방식"으로 한정
> 자동화율 혼동 방지: #1은 "자동 판정", #4는 "자동 종결"(측정 기준 상이 — 면접 시 구분 답변)

```text
대량 판정 데이터를 다뤄왔습니다. 규칙·매뉴얼·이슈 이력처럼 흩어진 데이터를 Graph DB(Neo4j) 스키마로 직접 모델링하고, 문서·도메인 2계층 GraphRAG로 다중 홉 질의를 가능하게 했습니다. 그 위에서 LangChain 기반 Multi-Agent가 판정한 결과를 다시 그래프에 축적했습니다. 검색 아키텍처는 Vector DB와의 통제 A/B 실험으로 결정했고, 폐쇄망용 sLLM 파인튜닝도 직접 수행했습니다. 원칙은 하나, 틀리면 안 되는 판정은 모델이 아니라 사실이 한다는 것입니다. 계측·검사 데이터는 시계열이 중심이라 성격이 다르지만, 흩어진 데이터를 관계로 묶어 근거를 추적 가능하게 만드는 일은 도메인을 가리지 않습니다.

#1 | 대량 판정 데이터 자동 분류 시스템 개발·현업 운영 — 75% 자동 판정, 리뷰 TAT 50% 단축
[문제 정의]
- 과제당 엔지니어 10명이 수백 종 규칙이 섞인 수십만 건 수작업 판정, 고위험 건에 쓸 시간이 잠식
[주요 활동]
- 규칙 단위로 데이터를 분해해 판정 경로 선언 — 사실 질의로 확정되면 결정론 로직, 나머지는 RAG 기반 LLM 추론과 출처별 신뢰도 적재
- MCP로 데이터 접근 표준화, 갱신 시 수집~판정~리포트 무인 수행
[주요 성과]
- Pilot false violation 20% 감소로 사업부 최초 실과제 적용, 확장 후 검토 75% 자동 판정·TAT 6일→3일
- false violation 90% 감소·자동 종결분 결함 유출 0건, 확정 판정 500건 환류로 판정 정확도 70→95%

#2 | 흩어진 이종 데이터를 단일 Graph DB로 모델링·통합 — 근거 확보 8ms, 운영 노드 약 1.6만
[문제 정의]
- 판정 근거가 벤더 매뉴얼·방법론 문서·파라미터 카탈로그·수년치 이슈 이력에 흩어져, 이들을 잇는 다중 홉 질문에 답할 수 없음
[주요 활동]
- 노드 20종·관계 33종 스키마를 직접 설계해 규칙·파라미터·메시지·문서·이슈를 한 그래프에 적재
- 문서 계층과 도메인 계층을 관계로 이어 벡터 히트가 도메인 그래프로 확장되는 2계층 GraphRAG
- 전 노드·관계에 출처·신뢰도 필드로 근거 추적, JSONL 계약 기반 멱등 적재

[주요 성과]
- 폐기된 선행 규칙을 경유해야 도달하는 답 등, 평면 카탈로그로는 불가능한 다중 홉 질의를 8ms에 확보
- 별도 도메인 그래프도 노드 14종·관계 23종 설계, 구조 정보만 7문항이던 정답을 패턴 지식 계층으로 12문항까지 개선

#3 | Vector DB와 Graph DB 통제 A/B 실험 — 정답 14→19건, 전문검색 2.2배
[문제 정의]
- 방식 변경 제안마다 "지금 Vector DB로 안 되나"가 따라붙어 측정으로 답함
[주요 활동]
- 동일 코퍼스 1,358쪽 적재 — Milvus 4,344청크(프로덕션 설정) vs Graph DB 노드 3,900여 개, 임베딩 서버 공유·답변/채점 모델 동일·익명 채점(26문항)
[주요 성과]
- 검색 적중률을 고정한 채 증거 전달량만 늘려 정답 14→19건 — 병목이 검색이 아니라 근거 전달임을 입증
- 정확 토큰 지배 문서군에서 전문검색이 벡터검색의 2.2배, 재순위 모델은 질문당 106초로 상시 사용 불가

#4 | 판정·조치 이력 그래프로 실행할수록 좋아지는 루프 구축 — 84% 자동 종결, 모델 판정 0건
[문제 정의]
- LLM 단독 판정은 같은 건에 매번 다른 답이라 품질 기록 불가, 통한 조치도 남지 않아 매번 다시 학습
[주요 활동]
- 실행 133건의 조치·검증 결과를 그래프에 적재, 다음 검증이 확인한 것만 지식으로 승격하고 근거가 무너지면 강등

- 실과제 5개 블록 판정 5,700여 건의 84% 자동 종결 — 전량 사실 질의 기반, 모델 판정 0건이라 재실행 시 동일 결론
```
